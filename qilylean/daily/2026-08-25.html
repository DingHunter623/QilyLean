居安思危｜识别制造业八大浪费：从看见问题到解决问题的改善闭环

很多制造现场“看起来很忙”，却不等于持续创造价值。真正吞噬利润的，往往是长期潜伏在生产、物流、质量、工程与管理流程里的浪费。本期不只识别八大浪费，更把每一种浪费拉回真实场景：看见异常、追到根因、选对方法、Pilot验证、用数据确认，再固化成标准。

第一步看见不等于改善
第二步改善必须追到根因
第三步结果必须数据验证并固化

居安思危，不是制造焦虑，而是建立异常感知能力。 企业越是在订单正常、产线忙碌、交付尚可的时候，越需要识别那些“被习惯掩盖”的非增值活动。浪费如果不能被定义、量化、解决和防止反弹，就会持续侵蚀产能、现金流、质量与组织能力。

核心判断：识别浪费 ≠ 改善完成。 如果只是贴标签、喊口号或做一次现场整理，没有根因、指标和标准化，浪费很快会以另一种形式回来。
02

八大浪费，一眼看懂现场信号

先知道“它长什么样”，才能在现场快速捕捉异常。

1

过量生产

做得过早、过多，超出客户或下工序真实需要。

2

等待

人、机、料、信息没有同步，流程出现停顿。

3

搬运

物料在工序之间反复转移，却没有增加产品价值。

4

过度加工

做了客户不需要、标准不要求、工艺没必要的工作。

5

库存

原料、WIP、成品超过合理水平，占资金也掩盖问题。

6

动作

寻找、转身、弯腰、伸手、走动等非增值动作过多。

7

不良与返工

返工、重检、报废与客诉把一次价值创造变成多次成本。

8

人才未活用

把员工只当执行者，经验、技能与改善建议没有进入系统。

过量生产：不要用“多做”制造虚假安全感

超计划、提前生产、成品和WIP不断堆高。

真正的问题不是“做得快”，而是生产节奏没有被客户需求和下工序消耗约束。

案例

某装配车间为追求日报产量，提前多做两天成品。随后客户版本变更，一批产品标签与附件需重新调整，形成拆箱、返工、重复包装和再次搬运。

根因：计划考核偏向产量、生产与实际需求脱节、没有WIP上限和拉动约束。

改善：以订单与TT建立日计划，设置WIP上限；通过Pull、Kanban、FIFO和Heijunka约束“何时做、做多少”。

PullKanbanHeijunkaTTFIFO
WIP库存周转率库存天数计划达成率
没有需求约束的产出，很可能只是把今天的问题搬到明天。

等待：不是催人快一点，而是消除流程断点

人等料、机等人、工单等审批、换型后等确认。

把等待拆成时间段，才能判断瓶颈在检验资源、责任界面，还是审批机制。

案例

某电子装配线换型后，班组完成调机，但首件需品质与工程依次确认，责任分工不清，整线等待40分钟。

根因：确认串行、响应责任不清、换型参数与首件标准没有前置。

改善：建立首件RACI、并行确认、参数预设和换型检查表；结合SMED拆分内外部作业，异常超时由Andon触发。

SMED线平衡Andon标准作业
等待时间CTOEE停机时间
目标不是让每个人都“看起来更忙”，而是让价值流连续起来。

物料车反复穿梭、临时中转区越来越多、路线交叉。

用Spaghetti Diagram把真实路线和距离画出来，比“感觉物流很忙”更有说服力。

案例

某工厂注塑件先到临时区，再进入仓库，随后到备料区，最后才配送至装配；一个周转箱正式使用前被反复搬动三次。

根因：Layout与物流策略分离、仓储节点过多、线边补料规则不清。

改善：绘制Spaghetti Diagram，重构Layout和物流路径；按场景采用使用点供料、线边超市、FIFO或Milk Run。

LayoutSpaghetti Diagram使用点供料Milk Run

优化物流，不是把叉车开得更快，而是减少必须搬的距离与次数。

过度加工：先问“能否取消”，再问“如何做快”

重复检验、重复录入、超标准加工、复杂流程解决简单问题。

先做增值 / 必要非增值 / 非增值分类，再用ECRS从“删除”开始。

案例

某功能件已有全检，现场又增加重复擦拭和二次复检。额外工序没有降低不良率，却拉长节拍并增加人力。

根因：“多做一道更保险”的惯性、客户需求与内部标准边界不清。

改善：把工序分为增值、必要非增值、非增值；应用ECRS，优先Eliminate，再考虑Combine、Rearrange、Simplify。

增值 / 必要非增值 / 非增值ECRS工艺评审

客户不需要、标准不要求、风险也未降低的工作，应首先被挑战。
05

库存：不要让缓冲区把真正的问题藏起来

WIP高、找料困难、呆滞料上升、库位不断扩张。

库存治理不是“一刀切清仓”，而是逐步降低缓冲，同时提高系统稳定性。

案例

某工厂为了防缺料长期大量备料，结果仓库频繁找料、混料，部分电子物料临期报废；库存反而掩盖计划、FIFO和编码管理问题。

根因：把库存当成对抗不确定性的唯一手段，没有治理变异源。

改善：用VSM确认库存位置与等待时间；按Pull、FIFO、Min-Max、Kanban和库存分类管理逐步降低水位。

VSMFIFOMin-MaxKanban库存分类
库存金额库存持有天数WIP呆滞率
精益不是追求“零库存”的口号，而是让库存水平与真实风险相匹配。
06

动作：把人的精力留给增值动作

频繁转身、弯腰、伸手、寻找、跨步与重复取放。

用录像或动作观察把一个循环拆开，距离、频次、姿势都可以量化。

案例

某装配岗位主料在左后方、辅料在右下方、工具在线体背面，每装一件都要转身、伸手和弯腰。

根因：工位按“哪里有空放哪里”形成，没有依据动作频次与人因工程设计。

改善：运用动作经济原则、ECRS、5S和工位设计；高频物料进入黄金作业区，双手动作尽量同步，工具定点定位。

一个工位的厘米级改善，乘以每天数千次循环，就是可观的时间与疲劳损失。

目标不是“更早检出不良”就结束，而是让过程能力和防错机制降低制造不良的概率。

案例

某批端子压接高度波动，现场为赶交期一边生产一边返工，虽然勉强完成出货，却增加工时并造成一致性风险。

根因：设备参数、模具寿命、首件确认和过程监控未形成闭环。

改善：异常先遏制流出，再用5Why / 8D追因；通过PFMEA、Poka-Yoke、SPC、Control Plan和首件标准固化。

5Why / 8DPFMEAPoka-YokeSPC
FPYDPPM返工工时COPQ
质量改善的方向，是异常不流出、根因不重复、过程越来越不容易做错。

建议机制的价值不在“收集多少条”，而在是否能快速评估、验证、固化和复制。

案例

某关键工序老员工早已发现治具定位存在偏差风险，也提出简易防错思路，但现场只关注赶产量，数月后发生批量不良。

根因：缺少改善入口、责任人、验证机制和反馈闭环。

改善：建立“异常提出 → 快速评估 → Pilot → 数据验证 → 标准化 → 分享”的Kaizen机制，结合QCC、OPL、技能矩阵和多能工培养。

04

现场快速识别：八个问题先问一遍

巡线不只是“看6S”，而是沿着价值流持续追问。

1现在生产的数量和时间，是否真正由客户或下工序需求触发？
2人、设备、物料、检验或信息之间，哪里正在等待？
3物料为什么要搬到这里？这一次搬运能否取消或缩短？
4这道加工、检查或录入，客户是否需要？风险是否真的降低？
5这些库存是在保障流动，还是在掩盖计划、质量、设备和供应问题？
6操作员是否频繁寻找、转身、弯腰、伸手或离开工位？
7返工、重检是否已经“习以为常”？同类问题有没有再次发生？
8一线员工发现的问题，有没有进入评估、验证、标准化和分享流程？

居安思危：在“还没有出大问题”时，把浪费解决掉

制造业真正的竞争力，不只是把产品做出来，而是以更少的浪费、更稳的质量、更短的周期、更高的协同效率持续交付价值。识别浪费，不是挑毛病；解决浪费，也不是一次运动。 它是一套从现场事实出发，用工程数据识别问题、用精益方法验证改善、再把成果固化为标准的经营机制。
