# QilyLean 精选简报统一版式规则

适用范围：所有《精选简报》页面，包括现有页面维护与后续新发布页面。

## 强制规则

1. 每期简报只允许内容、主题、图表和案例不同；页面主框架必须一致。
2. 页面宽度统一继承 QilyLean 全站内容轴：`--qily-wide-content`，当前标准为 1560px，并使用全站 `--qily-wide-gutter` 安全边距。
3. Hero、顶部翻页区、目录、正文各章节、知识链、表格与图表均必须沿用同一左右内容轴。
4. 禁止单篇简报设置私有正文宽度，例如 920px、1080px 等独立 `max-width`。
5. 禁止单篇简报设置独立 Hero 宽度、独立正文容器、独立页面框架或通过额外居中窄栏制造“文章站”视觉。
6. 单篇 CSS 只允许处理该期专属组件，例如图表、表格、流程图和响应式细节；不得覆盖统一内容轴。
7. 公共版式以 `/qilylean/daily/brief-layout-standard.css` 为基准。后续新简报如存在单篇 CSS，必须引用该标准并遵守上述约束。
8. 如单篇样式与统一版式冲突，以统一版式优先，按“少数服从多数”原则整改。

## 验收标准

- 宽屏下与既有标准精选简报页面保持一致的左右边界。
- 正文、卡片、图表、知识链不得出现比全站标准轴更窄的独立内容框。
- 平板和手机端仅做响应式换列与安全边距收缩，不改变统一版式逻辑。

> 原则：**精选简报只保留内容差异，不保留任何专属页面宽度与独立模板感。**
