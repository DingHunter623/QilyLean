制造改善方法体系图谱

八个能力域分别对应典型问题、核心方法和标准输出，便于企业负责人、项目经理及制造团队快速判断专业匹配度。

流程与交付

VSM / LT / WIP

识别订单信息流、物料流、生产节拍、等待、库存和发货节奏之间的断点。重点不是画图，而是形成改善优先级、责任边界和跨部门行动。

输出：现状图、未来态、LT结构、WIP控制和交付改善路径。
数据与产能

标准工时 / UPPH / 线平衡

IE 7 Tools · ECRS · 动作经济原则
运用IE七大手法识别作业、流程、动线与浪费，再以ECRS（取消、合并、重排、简化）及动作经济原则重构作业方法；用标准工时、UPPH和线平衡验证改善成效，支撑产能、排程、报价、成本及ERP/MES参数。

输出：工时版本、标准产能、线平衡方案、ECRS改善清单、人机配置、节拍和排程基础数据。
设备与换型

OEE / SMED / TPM

把停机、速度损失、换型等待、首件确认、不良返工和物料准备纳入统一损失结构。SMED不是催人更快，而是标准化换型系统。

输出：损失结构、换型流程、工具定置、参数基准和首件确认。
质量与异常

IATF 16949 / 六大工具

APQP · PPAP · FMEA · MSA · SPC · CP
以汽车质量管理体系贯穿产品与过程策划、风险预防、测量系统、统计控制和量产批准；再用5M2E识别要因、8D解决跨部门异常、PDCA验证并固化改善，避免只在问题发生后被动纠正。

输出：APQP/PPAP文件链、FMEA与控制计划、MSA/SPC验证、8D闭环、Poka-Yoke和过程控制机制。
布局与物流

Factory Layout / 精益物流

新工厂设计规划不是先画漂亮Layout，而是先定义产品、产能、工艺、物流、人员、设备、公辅、品质和扩展边界。

输出：人流物流动线、库位、配送频次、WIP控制和扩展弹性。
管理与固化

DMS / 6S / 目视化

目视化不是贴标识，而是把状态、边界、责任、异常、标准和节奏变成现场共同语言。

输出：DMS、6S红线、点检、看板、表单和复盘机制。
数智化协同

ERP / MES / APS

数智化工厂先做数据地基，再谈软件、大屏和自动化；否则系统只会放大现场混乱。

输出：BOM、路线、工时、产能、计划、实绩和库存口径统一。
项目机制

PMO / 阶段门 / 横向复制

以项目机制推动改善，不依赖个人英雄主义；用阶段门管理范围、风险、责任、验证和复制。

输出：试点验证、培训稽核、复盘沉淀和横向复制。
