CAPABILITY | FLOW

流程与交付

从客户需求、价值流和瓶颈识别出发，把改善活动落实为可执行、可验收、可复盘的工程闭环。

价值流与单件流

VSM / CT / C-O / WIP / TT / LT / VAT / VAR / PCE，结合未来态设计推动流动化与节拍管理。

交付重点 | 现状图 → 浪费识别 → 未来态 → 责任人 / 节点 / 指标

标准工时与线平衡

标准动作拆解、秒表测时、宽放、UPPH、人力与工位负荷，支撑产能评估和排产。

交付重点 | 标准工时库 → 产能模型 → 人力配置 → ERP/PMC 数据接口

布局与物流

Layout、物流路线、WIP、搬运、FIFO、定置与目视化，减少无效移动和跨区等待。

交付重点 | Spaghetti → 距离 → 频次 → 人时 → 布局方案

CAPABILITY | DATA

数据与产能

把现场数据做成排产、负荷、人力、交期和异常管理的共同语言。

生产实绩与滚动排程

订单需求、当日计划、累计实绩、未完成、超产、欠产、尾单结单与交期联动。

重点 | 净需求 / 已排 / 实绩 / 未完成 / 状态 / 日期逻辑

标准工时库

产品编码、标准工时、瓶颈、工位数、负荷与工艺路线维护，为 PMC 和 ERP 提供工程参数。

重点 | 数据完整率、覆盖率、版本、来源和审批

经营指标

OEE、UPPH、线平衡率、良率、达成率、换线时间、库存与异常闭环。

重点 | 指标口径统一，避免只看结果不看过程损失

CAPABILITY | EQUIPMENT

设备与换型

围绕停机、换型、设备能力和安全防错，把设备问题转化成标准与机制。

SMED

内外部作业分离、并行作业、工装预置、参数标准化和首件确认，压缩换线换模时间。

TPM / OEE

可动率、性能率、良率与六大损失，结合点检、保全和异常分层响应。

安全与防错

设备互锁、治具防呆、门禁/风淋、铆压/注塑防护，以及异常复位条件。

CAPABILITY | QUALITY

质量与异常

质量问题不止于判退：从发生、流出、系统原因和机制原因形成闭环。

8D / 5Why / 5W2H

围绕问题定义、遏制、根因、纠正、验证、标准化及经验横展。

过程质量

直通率、首件、巡检、异常反馈、防错、工艺参数、Control Plan 与 PFMEA。

体系接口

IATF 五大工具与现场动作结合，不把 APQP / FMEA / SPC / MSA / PPAP 停留在表单。

CAPABILITY | LAYOUT

布局与物流

用面积、距离、物流频次、搬运时间和 WIP 定量评价布局，而不是只看“整齐”。

Factory Layout

设备、工位、仓储、通道、人员动线和物流动线联合规划。

WIP / FIFO

库存点、容器数量、先进先出、最大最小库存和异常隔离。

目视化

区域、通道、定置、状态、红黄绿灯、看板和禁拍/安全标识按实际使用场景定义。

CAPABILITY | MANAGEMENT

管理与固化

改善结束并不等于项目结束，必须进入标准、审核、培训、数据监控和责任机制。

标准化

SOP / WI / 工艺标准 / 参数标准 / 点检标准 / 交接标准 / 版本控制。

6S / 稽查

标准、责任区、评分、异常、整改、复查与月度奖惩机制。

机制闭环

问题池、责任人、节点、指标、周会/月会、升级机制和复盘。

CAPABILITY | DIGITAL

数智化协同

数字化不是把表单搬上系统，而是让业务规则、主数据、工程参数和现场反馈形成闭环。

ERP / MES / APS

订单、BOM、工艺、工时、产能、库存、领退料、实绩与排程接口。

Excel / 自动化

工程模型、排产、标准工时、实绩滚动、异常预警和管理看板。

AI 应用

文档、知识库、分析、代码与自动化辅助；必须有数据来源、业务边界与人工复核。

CAPABILITY | MECHANISM

项目机制

明确项目目标、责任、阶段输出、验收口径和知识沉淀，保证改善可持续。

启动

问题定义、边界、资源、数据、目标和项目节奏。

执行

现场观察、数据采集、方案评审、试运行、风险控制和结果验证。

固化

标准、培训、审核、数据监控、复盘、知识库与下一轮改善入口。
