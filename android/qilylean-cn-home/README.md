# 精益制造经验分享｜QilyLean｜启力精益 中国站桌面 v1.0.0

专门面向 **QilyLean｜启力精益中国站（qilylean.cn）** 的 Android 免 Root 桌面 APP。  
它与国际站 `QilyLean Home` 独立存在，不修改、不替代国际站桌面。

## 应用标识

- APP显示名称：`精益制造经验分享`
- 个人品牌：`QilyLean｜启力精益`
- 工程名称：`QilyLean CN Home`
- 包名：`cn.qilylean.home`
- 版本：`1.0.0 (1)`
- minSdk：23
- targetSdk / compileSdk：36

## 核心能力

- 秒级时钟、公历、星期、年度周次、中国农历；
- 中国站首页、精益制造、工业工程、标准化、工厂规划、数智工厂、方法框架、代表项目直达；
- 知识索引、精选简报、资源协同、关于本站直达；
- Times26001 本机直接启动；未安装时进入中国站技术支持页；
- IE / 精益工具、PMC / 排产、OEE / UPPH / 线平衡入口；
- 系统设置、默认桌面、应用抽屉等本机快捷管理；
- 中国站专属隐私政策、用户协议与技术支持入口；
- 免 Root，可随时切回原系统桌面。

## 边界

- 只服务于 `qilylean.cn` 中国站知识与工具入口；
- 不把国际站商业合作内容迁入中国站桌面；
- 不读取 IMEI、序列号、手机品牌、型号等设备身份信息；
- 不申请 `QUERY_ALL_PACKAGES`；
- 应用抽屉信息仅在本机展示，不上传、不用于广告或用户画像。

## 与国际站桌面的关系

- 国际站桌面：`com.qilylean.home` / QilyLean Home；
- 中国站桌面：`cn.qilylean.home` / 精益制造经验分享（品牌：QilyLean｜启力精益）；
- 两者包名、链接体系、法律页面、发布节奏相互独立。
