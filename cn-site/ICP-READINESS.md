# qilylean.cn｜ICP 与正式上线就绪清单

## 当前状态

- 域名：`qilylean.cn` 已注册并完成个人实名认证；当前服务状态已恢复为“正常”，DNS 托管于 DNSPod。
- 云资源：腾讯云上海轻量应用服务器已创建，Ubuntu Server 24.04 LTS 64bit，2核/2GB/40GB SSD/3Mbps/200GB/月。
- 发布链：GitHub `main` → Actions → SSH → 腾讯云服务器的预生产部署链已首次跑通。
- 预生产：Nginx 仅监听 `127.0.0.1:8080`；中国站保持 `noindex,nofollow` 与 `robots.txt Disallow: /`。
- 主体：当前未注册公司、无营业执照。

## 合规判定

腾讯云当前备案规则要求网站内容与备案主体性质相符；个人备案网站不能涉及企业、团体等内容，个人通常只能开办个人博客、空间类或其他个人性质网站。

QilyLean 当前中国站包含新工厂/新产线规划、精益改善项目交付、目视化项目、数字化工厂、APP/工业数字工具和官网建设等业务型内容，因此在主体仍为个人的情况下，不把这套业务型站点直接作为个人备案公网网站上线。

这不是技术阻塞，而是“主体—内容一致性”上线 Gate。

## 后续允许的两条真实路径

### 路径 A｜未来企业主体备案

适合保持现有 QilyLean 业务型官网定位。

1. 注册公司并取得营业执照；
2. 按接入商要求处理腾讯云账号、域名实名与备案主体一致性；
3. 以单位主体提交 ICP 备案；
4. 备案通过后开放业务型中国站。

### 路径 B｜个人主体备案

仅在中国站真实定位调整为个人性质网站时采用。

- 内容必须长期保持个人性质；
- 不使用企业/团体身份表述；
- 不以备案审核为目的临时删改，审核后再恢复不匹配业务内容。

如果中国站仍承担 QilyLean 商务服务与项目承接入口，则不采用该路径。

## 当前阶段下一步

1. 域名状态已正常，继续维持 DNSPod 托管但不急于正式公网解析；
2. 暂不为赶进度强行推进与实际业务内容不匹配的个人备案；
3. 继续完成中国站视觉、响应式、速度、404/50x、HTTPS 配置模板和上线脚本；

5. 正式备案主体路径确认前，公网开放 Gate 保持锁定。

## DNS 预案

正式允许解析时：

```text
@     A      <腾讯云服务器公网IPv4>
www   CNAME  qilylean.cn
```

公网 IPv4 不写入公开仓库文件或 Issue。
