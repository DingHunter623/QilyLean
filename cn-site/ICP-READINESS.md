# qilylean.cn｜ICP 与正式上线就绪清单

更新时间：2026-09-16

## 当前状态

- 域名：`qilylean.cn` 已注册并完成个人实名认证，DNS 托管于 DNSPod。
- 云资源：腾讯云上海轻量应用服务器已创建，Ubuntu Server 24.04 LTS 64bit，2核/2GB/40GB SSD/3Mbps/200GB/月。
- 发布链：GitHub `main` → Actions → SSH → 腾讯云服务器的预生产部署链已跑通。
- 预生产：Nginx 仍按预生产方式运行；中国站继续保持 `noindex,nofollow` 与 `robots.txt Disallow: /`，直到正式上线 Gate 全部完成。
- 主体：个人。
- ICP：个人 ICP 备案已审核通过；正式上线前必须将核准备案号准确写入网站底部，并链接至工业和信息化部备案管理系统。
- 内容定位：个人制造业知识与实践分享站。

## 合规基线

中国站长期保持个人知识分享性质，仅发布精益生产、工业工程、标准化作业、现场改善、制造数据、数智工厂、学习笔记与实践复盘等内容。

以下内容不进入中国站：项目合作、商务合作、业务承接、签单、报价、收费、付款、合同、发票、咨询预约、销售线索、客户招揽、资源撮合、提成/分成及其他直接或潜藏的经营信息。

`.cn` 不做 `.com` 的机械镜像，不以自动跳转、iframe、代理展示或主要入口方式把访客导向国际站商业页面。

## 正式上线前下一步

1. 写入工信部核准的完整 ICP 备案号；
2. 确认备案号链接指向 `https://beian.miit.gov.cn/`；
3. 配置 `qilylean.cn` 与 `www.qilylean.cn` 的正式 DNS；
4. 开放公网 80/443，并完成 Nginx 生产站点切换；
5. 配置有效 HTTPS 证书与自动续期；
6. 统一主域并配置 HTTP → HTTPS；
7. 完成 PC / 平板 / 手机 / 微信环境回归；
8. 完成内容合规自动检查；
9. 正式上线确认后再解除 `noindex` 和 `robots.txt Disallow: /`；
10. 生成并验证 `sitemap.xml`，随后提交国内搜索资源平台；
11. 网站正式联通后按适用要求办理公安机关国际联网备案。

## DNS 预案

正式允许解析时：

```text
@     A      <腾讯云服务器公网IPv4>
www   CNAME  qilylean.cn
```

公网 IPv4 不写入公开仓库文件或 Issue。
