Times26001 隐私政策

适用于 Times26001 Android 应用。当前版本保持原有 IE 测时、闹钟、倒计时、时间日历、天气与位置等功能。

生效日期：2026年8月27日　当前版本：v1.1.14（versionCode 17 / API 36）　联系邮箱：admin@qilylean.com

一、核心说明

Times26001以IE现场测时、时间研究、倒计时、闹钟、北京时间、万年历及天气预报辅助为主要功能。当前版本不设账号、不投放广告、不接入第三方广告或统计SDK，不主动上传生日、闹钟、倒计时或IE测时记录等本地数据。

二、我们处理的信息

1. 本地设置与功能数据

主题、字号、色弱模式、生日、闹钟、倒计时、秒表分段及相关偏好保存在用户设备本地。生日仅用于星座相关展示，可不填写。

2. 日期与时间

应用读取设备当前日期、时间和时区，用于北京时间、公历、农历、节气、黄历、周次、闹钟和倒计时计算，原则上在设备本地处理。

3. 天气、城市与位置

用户可搜索城市或主动点击“使用当前位置”查询天气。城市搜索文字会发送至 Open-Meteo 地理编码服务；使用当前位置时，仅请求 Android 前台位置权限，不使用后台位置。按用户实际授权取得的坐标用于当前天气请求，并可能发送至 BigDataCloud 客户端反向地理编码接口解析省、市、区县名称，再发送至 Open-Meteo 获取当前实况和未来7天预报。最近一次选定地点及成功天气结果可保存在本机，拒绝位置权限不影响城市搜索、IE测时、闹钟和倒计时。

三、权限使用说明

  • 通知权限：显示闹钟和倒计时到期通知。
  • 精确闹钟权限：尽可能按用户设定时间触发提醒。
  • 振动与唤醒相关能力：用于已启用提醒的振动、声音和到期提示。
  • 前台位置权限（精确/粗略）：仅在用户主动使用“当前位置”查询天气时申请。
  • 网络访问：用于天气/城市查询，以及用户主动访问 QilyLean 中国站、隐私政策、用户协议和技术支持页面。

本应用不因核心功能申请通讯录、短信、通话记录、相机、麦克风、文件全盘访问、后台位置或广告标识符权限。

四、存储、共享与删除

功能数据主要保存在本机 localStorage、Capacitor Preferences 或 Android 系统通知计划中。当前版本不向开发者服务器、广告商或数据经纪商出售或出租本地数据。天气查询仅为完成用户主动请求而向相关服务发送必要的城市关键词或经纬度。

用户可在应用中删除相应记录，也可在 Android 系统设置中清除应用数据或卸载应用。

五、中国站与联系邮箱

应用内官方网址使用 QilyLean 中国站 https://qilylean.cn。联系邮箱继续使用 admin@qilylean.com，用于问题反馈与技术支持。

六、用户权利与政策更新

用户可自主决定是否填写生日、创建提醒、保留测时记录或授权天气位置，并可随时删除或清除。若未来新增账号、云同步、在线备份、统计分析、广告、付费服务或新的第三方SDK，将根据实际功能更新本政策并依法处理。
