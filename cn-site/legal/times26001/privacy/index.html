Times26001隐私政策

适用于 Times26001 Android 应用（安卓桌面显示名称为“个人时间管理”）。应用提供日常时间管理、工业工程现场测时及天气辅助能力，由 QilyLean｜启力精益开发。

生效日期：2026年8月27日　修订日期：2026年11月4日　当前版本：v1.1.15（versionCode 18 / API 36）　官网邮箱：admin@qilylean.com
核心说明：本应用以IE现场测时、时间研究、倒计时、闹钟、北京时间、万年历及天气预报辅助为主要功能。当前版本不设账号、不投放广告、不接入第三方统计或广告SDK，不主动上传生日、闹钟、倒计时或IE测时记录等本地数据。天气“当前位置”仅在用户主动触发时申请Android前台位置权限；系统可能根据用户授权提供精确位置或粗略位置，应用按实际授权结果用于天气定位，不使用后台位置。

一、我们处理的信息

1. 本地设置与功能数据

主题、字号、色弱模式、生日、闹钟、倒计时、秒表分段及相关偏好保存在用户设备本地，用于提供应用功能。生日仅用于星座相关展示，可不填写。

2. 日期与时间信息

应用读取设备当前日期、时间和时区，用于北京时间、公历、农历、节气、黄历、周次、闹钟和倒计时计算。该信息原则上在设备本地处理。

3. 天气、城市与位置信息

用户可选择搜索城市或主动点击“使用当前位置”查询天气。城市搜索文字会发送至Open-Meteo地理编码服务；使用当前位置时，仅请求Android前台位置权限，不声明或使用后台位置。Android系统及用户可决定授予精确位置或粗略位置，Times26001按实际授权结果取得坐标用于完成当前天气请求。获得的坐标会发送至BigDataCloud客户端反向地理编码接口以解析省/市/区县名称，并发送至Open-Meteo天气接口以返回当前实况和未来7天预报。最近一次选定地点（可能包含经纬度）及成功天气结果会保存在本机localStorage，便于下次快速打开。拒绝位置权限不影响城市搜索和IE测时、闹钟、倒计时等核心功能。

4. 技术运行信息

当前版本不主动建立开发者服务器日志，也不集成第三方崩溃统计。Android系统、应用商店或设备厂商可能依据其自身规则处理安装、崩溃和设备兼容信息，此类处理由相应平台负责。

二、权限使用说明

  • 通知权限：用于显示闹钟和倒计时到期通知。
  • 精确闹钟权限：用于尽可能按用户设定时间触发核心闹钟和倒计时功能。
  • 振动与唤醒相关能力：用于在用户已启用提醒时提供振动、声音和到期提示。
  • 前台位置权限（精确/粗略）：仅在用户主动使用“当前位置”查询天气时申请。Android系统可能根据用户选择授予精确位置或粗略位置；应用优先使用系统当前可提供的位置结果完成天气查询，并在无法获得高精度结果时使用可用的近似位置。用户可在APP“设置 → 天气与位置权限”查看权限状态并主动申请，也可拒绝授权并改用城市搜索。本应用不使用后台位置。
  • 网络访问：用于用户主动查询Open-Meteo天气/城市数据，以及访问QilyLean官方网址、隐私政策、用户协议或技术支持链接；IE测时、计时、闹钟、黄历等本地核心能力不依赖天气服务。

除用户主动使用天气“当前位置”时申请前台位置权限外，本应用不因核心功能申请通讯录、短信、通话记录、相机、麦克风、文件全盘访问、后台位置或广告标识符权限。

三、数据存储、共享与删除

存储位置

应用功能数据保存在本机localStorage、Capacitor Preferences或Android系统通知计划中。

对外共享

当前版本不向开发者服务器、广告商或数据经纪商出售、出租用户本地数据。天气查询时，仅为完成用户主动请求，将城市关键词或定位获得的经纬度发送至Open-Meteo相关接口；使用当前位置时，经纬度还会发送至BigDataCloud反向地理编码接口以解析省/市/区县名称。

保留期限

应用本机保存的数据通常保留至用户在应用中删除、清除应用数据或卸载应用。第三方天气/地理服务对网络请求的处理受其自身政策约束；Times26001不建立开发者侧天气位置数据库。

删除方式

用户可删除闹钟和计时记录，或在Android系统设置中清除应用数据、卸载应用。

四、未成年人、跨境与安全

本应用面向一般时间管理和工业工程测时场景，不专门面向儿童收集信息。天气功能依赖第三方Open-Meteo与BigDataCloud网络服务，相关请求可能经过用户所在地区以外的网络基础设施；除天气查询和位置名称解析所必需的城市关键词或经纬度外，Times26001不向这些服务发送生日、闹钟、秒表分段或其他本地业务数据。我们通过最小权限、前台按需调用、本地处理和不集成广告SDK降低数据风险；但任何设备和软件均无法保证绝对安全，请妥善保护设备锁屏和系统账号。

五、官方网址、官网邮箱与外部链接

应用底部可显示QilyLean｜启力精益官方网址与官网邮箱，用户可主动访问官方网址或发送邮件。QilyLean网站用于品牌介绍、工程内容、产品说明及技术支持。国内应用市场版本不通过应用内入口引导用户绕过应用市场下载、更新或安装APK。

六、用户权利与政策更新

用户可自主决定是否填写生日、创建提醒、保留测时记录或授权天气位置，并可随时删除或清除。若未来增加账号、云同步、在线备份、统计分析、广告、付费服务或新的第三方SDK，我们将在功能启用前更新本政策，并根据适用法律取得必要授权。

对本政策或应用数据处理有疑问，可通过admin@qilylean.com联系开发者。
