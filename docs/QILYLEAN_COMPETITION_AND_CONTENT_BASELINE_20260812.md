# QilyLean 竞争力升级与内容精选基线｜2026-08-12

> 本文件是《QilyLean官网全站建设与运维总规范 V2026.08.12 / R2》的专项执行补充。若旧脚本、旧工作流或历史页面与本文件冲突，以 R2 及本专项基线为准。

## 1. 品牌主轴

QilyLean 不以“精益工具数量”或“文章数量”证明专业度。核心定位统一为：

**把制造现场问题转化为可计算、可验证、可固化、可复制的运营资产。**

制造运营价值链统一表达：

**现场事实 → 工程数据 → 精益改善 → 质量保证 → 数智固化 → 知识资产。**

项目闭环统一表达：

**问题定义 → 数据基线 → 改善验证 → 标准固化 → 系统运行 → 组织复制。**

## 2. 三大核心业务与数智化增强边界

全站唯一核心业务分类为三大核心业务：

1. 新工厂／新产线规划
2. 精益改善项目
3. 目视化项目设计与交付
数字化工厂属于数智化增强能力，按三大核心业务的具体项目范围嵌入；QilyLean AI／APP 与官网属于自主数字作品和技术实证，不作为第四、第五、第六项核心业务，也不进入核心业务标准报价模块。

三大核心业务共同回到制造运营资产化主轴，并按问题定义、事实基线、方案设计、Pilot验证、标准固化和项目验收形成闭环。

## 3. 精选简报新规则

自 2026-08-12 起，公开简报从“日更数量型”转为“周度精品型”。

- 默认每个 ISO 周只保留 1 篇高价值公开简报。
- 评审维度：制造专业相关性、工程逻辑与数据、问题到结果闭环、证据与边界、原创复用价值、检索培训价值。
- 同周重复主题只保留综合价值最高的一篇。
- 泛职场、泛励志、低信息密度、模板化重复内容原则上不进入公开简报档案。
- 用户明确点名的精品内容作为保护项，可形成同周多篇的唯一例外。
- 简报公开数量必须读取精选后的真实数据源，不再把累计数量作为品牌竞争力指标。

### 强制保护项

- 2026-07-29｜从 EVT 到 MP：NPI 四阶段量产交付闭环（EVT / DVT / PVT / MP）
- 2026-08-08｜培训／Andon 与现场异常闭环
- 2026-08-09｜Ceiling／天花板、Benchmark、Target、Stretch Target
- 2026-08-12｜本周精选：汽车座椅开关 PMO 量产交付闭环

机器可读保护清单以 `qilylean/brief-curation-policy.json` 为唯一来源。

## 4. 首页竞争力表达

首页第一屏优先完成三件事：

1. 说明 QilyLean 是什么：制造运营资产化专业平台／个人专业品牌。
2. 说明怎样解决问题：现场事实、工程数据、改善验证、标准和系统固化。
3. 给出高价值下一步：代表项目与证据、问题初筛／项目合作。

不得重新用“3+3”、文章总量、工具堆砌抢占第一认知。

## 5. 防回退

以下情况必须阻断发布：

- 公开核心页恢复“3+3”业务分类。
- 每周出现非保护项之外的多篇公开简报。
- 7月29、8月8、8月9保护简报被删除或核心内容丢失。
- 简报目录、RSS、Sitemap、首页／信任中心统计继续引用已删除简报。
- 首页继续把历史累计简报数量作为核心竞争力证明。

## 6. 质量优先原则

**宁可少，不可水；宁可一篇可复用的工程资产，不要七篇低密度日更。**

每次新增简报都应回答：问题是什么、事实与数据是什么、如何判断、如何验证、如何固化、哪些边界不能直接复制。
