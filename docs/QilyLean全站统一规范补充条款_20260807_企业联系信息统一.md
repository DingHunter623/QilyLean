# QilyLean 全站统一规范补充条款｜企业联系信息统一

生效日期：2026-08-07

## 1. 唯一公开企业邮箱

QilyLean 全站公开联系邮箱统一为：`admin@qilylean.com`。

除历史档案确有保留必要且明确标注为历史资料外，任何公开页面、联系入口、合作入口、留言说明、技术支持、应用支持、隐私政策、用户协议、信任中心、结构化数据及自动通知说明，均不得继续展示个人 QQ 邮箱、Gmail 或其他旧公开联系邮箱。

## 2. 联系类模块统一要求

凡页面出现“交流”“联系”“合作”“咨询”“留言”“入驻”“支持”“技术服务”“项目交流”等具有对外沟通属性的模块，在已有电话或微信的情况下，应同步核对企业邮箱是否可见，并优先提供 `mailto:admin@qilylean.com` 直接发信入口。

全站悬浮“交流”弹窗至少包含：微信号、手机号码、企业邮箱；企业邮箱同时提供“复制邮箱”和“发送邮件”操作。

## 3. 全站页脚公共联系信息

使用全站公共导航框架的页面，在原有页脚内容基础上统一补充：

**QilyLean｜技术与项目联系 / Technical & Project Contact｜admin@qilylean.com**

该表述用于建立专业、统一、国际化的公开联系入口，不得扩写为“全球客服中心”“集团技术服务中心”等可能造成主体性质或业务规模误解的表述。

## 4. 主体与可信度边界

企业域名邮箱用于增强品牌身份一致性、正式沟通与邮件可信度，不等同于公司注册、政府备案、行业认证、客户背书或商业成交证明。

QilyLean 当前主体性质及签约、付款、证据口径继续以“信任中心”及正式合同规则为准。

## 5. 响应式与交互规范

邮箱地址在桌面端不得被无意义断行；窄屏端不得溢出容器。按钮、边框、留白、字体层级、Hover/Focus 状态须遵循全站现行 VI 与交互规范。

邮件链接统一使用 `mailto:admin@qilylean.com`；复制操作成功后应提供明确反馈。

## 6. 运维检查项

任何涉及联系方式、合作入口、页脚、支持页面或结构化数据的后续运维，发布前须至少检查：

- 公开邮箱是否统一为 `admin@qilylean.com`；
- 是否仍残留旧个人邮箱；
- 联系类模块是否遗漏企业邮箱；
- `mailto:` 是否指向正确地址；
- 桌面端与移动端是否无错位、挤压及异常换行；
- 缓存版本是否同步更新，避免线上继续加载旧联系方式。
