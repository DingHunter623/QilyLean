# R6 受控变更记录｜首页主标题与悬浮 Dock 归位规则

- 日期：2026-08-19
- 基线：QL-WEB-STD-001｜V2026.08.19 / R6
- 状态：已批准实施，待并入下一版母标准
- 影响对象：首页 Hero；全站右侧悬浮功能栏 Dock；静态物化器；CI/回归门禁

## 变更内容

1. 首页头号主标题在现有 V2 基础上再缩小一号：桌面最大字号由 56px 档降至 52px 档；981–1280px 最大字号由 52px 档降至 48px 档。正文、按钮、人物图、制造运营闭环不变。
2. 全站悬浮 Dock 保留按住时 X/Y 自由拖动能力，并继续执行视口边界约束。
3. Dock 不再保存任意拖动后的停靠位置；释放指针、取消拖动、窗口尺寸变化或页面恢复时，自动归位到视口右下角安全边距位置。
4. 清理历史 `qilyDockPositionV2` / `qilyDockTop` 本地存储，避免旧位置继续覆盖新基线。
5. PC/移动端按钮尺寸、字号、hover/active/focus/touch 反馈继续继承 Interaction Continuity V2，不降低既有交互基线。

## R6 对应原则

- 第 4.2 章 VI-03：字号保持清晰可读；本次仅对首页头号标题做受控缩放。

- 第 15 / 16 / 17 章：公共源、物化器、CI、回归验证同步更新，防止旧版位置记忆规则复活。

## 验收条件

- 首页 1920 / 1600 / 1440 / 1366 宽度下，主标题明显较 V2 小一号，三行语义保持完整且不与人物图挤压。
- Dock 初始静止位置为右下角；历史已保存位置不得影响初始位置。
- Dock 可在按住期间任意 X/Y 拖动，不越出可视窗口。
- 释放或取消拖动后，Dock 自动回到右下角。
- resize / pageshow 后 Dock 仍回到右下角。
- 点击各功能按钮时正常执行原功能，不因拖动判定误触。
- 全站 HTML 静态引用 Hero V3 / Dock Snapback V3 / Navigation V30 当前版本。
- CI 验证不得出现任意位置持久化、旧 Dock V2 缓存引用或首页 Hero V2 引用。
