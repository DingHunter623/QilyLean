# QilyLean全站统一规范补充条款｜编号徽章与交互悬停高对比

版本：V2026.08.05 R2  
生效日期：2026-08-05  
适用范围：QilyLean全站流程号、步骤号、核心业务序号、时间线编号、工作流编号，以及主行动按钮、胶囊入口、卡片操作按钮等真实可点击模块

## 1. 问题定义

### 1.1 编号徽章

- 圆形编号采用深青背景时，数字不得继承父级深色文字、透明度、滤镜或浏览器文字填充色。
- “背景存在”不等于“色界合格”；编号数字必须在正常显示、缓存回退、WebKit文字填充和公共样式覆盖下仍清晰可见。
- 用户指出某一页面后，必须主动扫描全站同类编号徽章，不得只修截图页面。

### 1.2 悬停后文字消失

- 真实可点击入口在正常状态可见，不代表悬停状态合格。
- 主行动、可信度条、胶囊按钮、卡片操作入口和表单按钮在鼠标悬停、键盘聚焦和按下状态下，均不得出现浅底浅字、深底深字、文字填充色未同步或伪元素遮挡文字。
- “从具体问题开始”“查看信任与边界”等可信度条入口属于全站公共组件，必须由公共悬停对比层统一管理，不得等待逐页截图后再加单页补丁。

## 2. 编号徽章统一视觉规则

- 背景：深青实底 `#075767`。
- 数字：纯白 `#FFFFFF`，同时设置 `color` 和 `-webkit-text-fill-color`。
- 描边：白色内描边，并使用青色外圈拉开与白色／浅色卡片背景的边界。
- 状态：`opacity:1`、`filter:none`、`mix-blend-mode:normal`、无文字阴影。
- 字重：不低于900；行高为1，数字在圆心垂直、水平居中。
- 核心业务01／02／03使用42px规格；普通流程1／2／3／4使用34px规格。

## 3. 悬停／聚焦／按下统一规则

### 3.1 悬停与键盘聚焦

- 背景：金色实底 `#FFE39B`。
- 文字：深色 `#17322D`。
- 边框：金棕色 `#C99A3E`。
- 同时设置 `color` 与 `-webkit-text-fill-color`，并同步覆盖按钮内部的`span`、`strong`等子元素。
- 强制`opacity:1`、`visibility:visible`、`filter:none`、`mix-blend-mode:normal`、无文字阴影。
- 允许轻微上移和阴影反馈，但不得让文字、图标或下横线被伪元素遮挡。

### 3.2 按下状态

- 背景：深青实底 `#073C47`。
- 文字：纯白 `#FFFFFF`。
- 下横线或强调色：浅金 `#FFE39B`。
- 按下反馈可轻微缩放，但文字必须保持清晰可见。

### 3.3 适用对象

- `.ql-trust-strip-actions`与`.ql-trust-actions`内的链接；
- `.hero-actions`、`.actions`、`.module-actions`、`.card-actions`、`.qily-ia-actions`内的链接和按钮；
- `.form-actions`、`.resource-stage`、`.service-contract`、`.contact-card`内的真实操作入口；
- `.resource-action`、`.qily-ia-button`、`.module-action`、`.project-list-action`、`.project-card-action`、`.service-contract-link`、`.share-button`及`.primary`按钮。

## 4. 编号徽章适用对象

- `.step-index`
- `.sequence-number`
- `.process-number`
- `.number-badge`
- `.workflow-number`
- `.timeline-number`
- `.process`、`.steps`、`.workflow`、`.timeline`等流程容器内，步骤卡片的首个数字`<b>`元素

## 5. 禁止事项

- 禁止深色数字叠加深色圆底。
- 禁止正常状态可见、悬停后文字消失或变成近似底色。
- 禁止仅修改页面内联CSS而遗漏公共样式和后续生成页面。
- 禁止使用半透明文字、滤镜、混合模式或文字阴影削弱识读。
- 禁止伪元素覆盖真实按钮文字。
- 禁止扩大修改范围改变卡片背景、文案、间距或结构；本规范只统一编号和真实交互状态的可读性。
- 禁止发布脚本或历史缓存把对比样式恢复为旧版本。

## 6. 发布与验收

- 全部公共页面必须同时加载统一编号徽章样式和交互悬停高对比样式。
- 发布器必须幂等：连续运行两次，第二次不得产生任何新增差异。
- CI至少验证：
  1. 行业资源入驻页“核验与发布流程”1—4编号仍存在；
  2. 项目合作三大核心业务序号仍存在；
  3. “从具体问题开始”“查看信任与边界”等公共入口文案仍存在；
  4. 编号CSS包含深青底、纯白字、WebKit文字填充、无透明和无滤镜规则；
  5. 悬停CSS包含金色底、深色字、子元素文字覆盖和深青按下状态；
  6. 全部公共页面均加载当前两个样式版本；
  7. 生成结果无旧版本引用、无重复资源、无空白脏差异。

## 7. 执行原则

- 收到“按全站规范排查”指令后，应主动完成：截图对象定位、正常／悬停／聚焦／按下四状态检查、同类选择器检索、公共样式修复、全站页面物化、CI防回退及主分支静态发布。
- 不得等待用户逐页截图后再修；同类问题应一次扫描、一次闭环。
