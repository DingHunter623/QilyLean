# QilyLean全站统一规范补充条款｜编号徽章高对比

版本：V2026.08.05 R1  
生效日期：2026-08-05  
适用范围：QilyLean全站流程号、步骤号、核心业务序号、时间线编号、工作流编号及同类圆形数字徽章

## 1. 问题定义

- 圆形编号采用深青背景时，数字不得继承父级深色文字、透明度、滤镜或浏览器文字填充色。
- “背景存在”不等于“色界合格”；编号数字必须在正常显示、缓存回退、WebKit文字填充和公共样式覆盖下仍清晰可见。
- 用户指出某一页面后，必须主动扫描全站同类编号徽章，不得只修截图页面。

## 2. 统一视觉规则

- 背景：深青实底 `#075767`。
- 数字：纯白 `#FFFFFF`，同时设置 `color` 和 `-webkit-text-fill-color`。
- 描边：白色内描边，并使用青色外圈拉开与白色／浅色卡片背景的边界。
- 状态：`opacity:1`、`filter:none`、`mix-blend-mode:normal`、无文字阴影。
- 字重：不低于900；行高为1，数字在圆心垂直、水平居中。
- 核心业务01／02／03使用42px规格；普通流程1／2／3／4使用34px规格。

## 3. 适用对象

- `.service-number`
- `.step-number`
- `.step-index`
- `.sequence-number`
- `.process-number`
- `.number-badge`
- `.workflow-number`
- `.timeline-number`
- `.process`、`.steps`、`.workflow`、`.timeline`等流程容器内，步骤卡片的首个数字`<b>`元素

## 4. 禁止事项

- 禁止深色数字叠加深色圆底。
- 禁止仅修改页面内联CSS而遗漏公共样式和后续生成页面。
- 禁止使用半透明数字、滤镜、混合模式或文字阴影削弱识读。
- 禁止扩大修改范围改变卡片背景、文案、间距或结构；本规范只统一编号徽章可读性。
- 禁止发布脚本或历史缓存把编号样式恢复为旧版本。

## 5. 发布与验收

- 全部公共页面必须加载统一编号徽章样式资源。
- 发布器必须幂等：连续运行两次，第二次不得产生任何新增差异。
- CI至少验证：
  1. 行业资源入驻页“核验与发布流程”1—4编号仍存在；
  2. 项目合作三大核心业务序号仍存在；
  3. 公共CSS包含深青底、纯白字、WebKit文字填充、无透明和无滤镜规则；
  4. 全部公共页面均加载当前编号徽章样式版本；
  5. 生成结果无旧版本引用、无重复资源、无空白脏差异。

## 6. 执行原则

- 收到“按全站规范排查”指令后，应主动完成：截图对象定位、同类选择器检索、公共样式修复、全站页面物化、CI防回退及主分支静态发布。
- 不得等待用户逐页截图后再修；同类问题应一次扫描、一次闭环。
