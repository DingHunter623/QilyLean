# QilyLean 中国大陆企业站｜启动基线

启动日期：2026-09-03
状态：BOOTSTRAP / 未上线 / 未开放索引

## 1. 项目定位

- `qilylean.com`：继续作为 QilyLean 全球主品牌站与完整知识/项目资产站，保持现有 GitHub Pages 生产链不变。
- 中国大陆企业站：使用独立大陆域名（最终域名待公司主体与域名确定）+ 中国大陆合规云资源 + ICP 备案。
- 两站品牌统一、业务统一、公司主体统一，但不做 100% 镜像复制，避免内容重复与 SEO 内耗。

## 2. 当前阶段硬约束

1. 不修改 `main` 分支现有 `qilylean.com` 生产环境。
2. 中国站所有开发先在 `cn-site-bootstrap-20260903` 隔离分支完成。
3. 公司正式登记前，不虚构公司全称、统一社会信用代码、ICP备案号、对公账户等法定信息。
4. 中国站正式域名确定前，页面必须保持 `noindex,nofollow` 或仅作为内部预览。
5. 正式备案完成前，不对外宣称已取得 ICP 备案。
6. 继承 QilyLean 现有 VI、交互连续性、跨端响应式、首屏性能、Guard/Poka-yoke 与发布回归基线。

## 3. 中国站建议信息架构

- 首页：首页价值主张 + 三大核心交付业务 + 三类数智增强能力
- 公司与品牌：企业主体、QilyLean 品牌、方法论与能力边界
- 核心业务：
  1. 新工厂 / 新产线规划
  2. 精益改善项目交付
  3. 目视化项目设计与交付
- 数智能力：
  4. 数字化工厂
  5. APP / 工业数字工具开发
  6. 官网建设与数字品牌基础设施
- 代表项目 / 能力证明
- 商务合作 / 联系我们
- 信任中心：营业执照主体、备案信息、隐私政策、版权、企业邮箱、合同/发票主体说明
- 全球主站入口：明确链接至 `https://qilylean.com/`

## 4. 双站内容治理

- `.com`：完整技术资产、知识资产、案例深度、国际化/多语言、长期 SEO 主资产。
- 中国站：企业身份、国内商务转化、合规信息、精选业务能力与高价值案例摘要。
- 中国站引用深度内容时优先链接 `.com`，不整站复制。
- `.com` 后续仅增加中国大陆企业站入口，不改变其现有核心 URL 与既有 SEO 结构。

## 5. 部署目标

生产架构建议：

`GitHub（唯一源代码 / 版本控制） → CI 构建中国站发布包 → 中国大陆云服务器/静态托管 → 中国站域名 → ICP 备案后正式上线`

要求：
- HTTPS
- HTTP/2 或 HTTP/3（由最终云/CDN条件决定）
- Brotli/Gzip
- 静态资源长缓存 + HTML 短缓存
- 404/50x 自定义错误页
- robots.txt / sitemap.xml
- 百度/Google/Bing 可独立控制索引策略
- 发布可回滚
- 不允许脚本重复刷新、首屏隐藏、旧版闪现

## 6. 上线 Gate

- [ ] 公司主体完成登记
- [ ] 中国站域名完成企业实名
- [ ] 大陆云资源确定并满足备案条件
- [ ] ICP 备案完成
- [ ] 企业法定信息写入 Trust / Footer
- [ ] 生产域名 HTTPS 正常
- [ ] PC / 平板 / 手机回归通过
- [ ] 微信内置浏览器回归通过
- [ ] 页面无明显旧版闪现、白屏、重复刷新
- [ ] 百度抓取、robots、sitemap、canonical 策略验收
- [ ] `.com` 与中国站双向品牌关联完成

## 7. 变更纪律

中国站建设继续执行 QilyLean 既有原则：

问题发现 → 根因分析 → 单点修复 → 全端验证 → 防错固化 → 发布。

禁止为赶备案或赶上线牺牲视觉质量、浏览速度、交互一致性和技术可信度。
