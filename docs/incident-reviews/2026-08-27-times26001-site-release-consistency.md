# Times26001 官网发布一致性事件检讨书与整改计划

**日期：2026-08-27**  
**范围：QilyLean 官网 / Times26001 官网分发 / 隐私政策 / 用户协议 / 全站联系方式与视觉版心治理**

## 一、检讨结论

本次问题不是单一页面漏改，而是发布治理失效。Times26001 已推进到 v1.1.14 / versionCode 17 / API 36，并完成三星 C55 真机验证，但官网直接下载仍停留在 v1.1.13 / code16；隐私政策、用户协议又分别保留了旧版本与旧生效日期；法律页仍使用独立 980px 版心；邮箱链接虽然已有部分全站样式，但法律页未完整继承，造成下划线视觉不连续。

最需要检讨的是：此前把“官网独立 APK”和“Google Play 候选”分开管理后，只做了口径解释，没有把“最新版本是否应该同步到官网”做成自动闭环；同时 CI 审计反而硬编码允许官网继续停留 v1.1.13。这相当于用门禁固化了错误状态。发布管理不能再依赖逐页记忆和人工补丁。

## 二、根因

1. **版本主数据多源化。** `app-release-manifest.json`、产品页、下载 JS、首页卡片、隐私政策、用户协议、支持页分别保存版本字符串，缺少真正的单一来源约束。
2. **发布链边界被误用。** Google Play Upload Key 与官网测试签名确实应分开，但“签名链分开”不等于“官网可以永久停留旧功能版本”。
3. **法律页未纳入发布关闭清单。** 升级 APP 时没有强制同步隐私政策、用户协议的版本号、生效日期与功能口径。
4. **历史组件样式脱离全站视觉轴。** `/legal/app-legal.css` 保留 980px 老版心，与全站 1560px 内容轴相冲突。
5. **联系方式规范覆盖不完整。** 全站链接规范已有 `text-decoration-skip-ink:none`，但法律页未完整继承，且没有对邮箱地址禁止换行形成硬性门禁。
6. **CI 规则存在硬编码。** 审计脚本直接写死 v1.1.13/code16 与 v1.1.14/code17，而不是从发布主数据派生，版本升级后自然产生漂移。

## 三、立即整改

本次整改将官网可安装包同步到 v1.1.14 / code17 / API36；更新所有当前发布面下载链接和 SHA-256；隐私政策与用户协议统一到 2026-08-27 生效、v1.1.14；法律页版心统一继承全站 1560px 内容轴；所有邮箱链接强制连续下划线、禁止地址中途换行；CI 改为从 `app-release-manifest.json` 派生当前版本并扫描发布面残留旧版本。

Google Play 正式分发继续使用 Upload Key / Play App Signing 链；官网 APK 继续作为独立测试签名分发链。两条签名链边界必须清晰，但当前功能版本不再无故脱节。

## 四、全站排查范围

排查对象包括当前 Times26001 产品页、首页/能力体系卡片、APP 支持页、下载/分享 JS、发布清单、产品概览素材、隐私政策、用户协议，以及所有使用 `/legal/app-legal.css` 的法律页面；同时检查全站 `admin@qilylean.com` 可见文本是否使用 `mailto:`，并统一邮箱下划线样式。

历史 CI 配方、历史构建记录和明确的归档资料保留原版本事实，不把历史事实误改成当前版本；但任何面向访问者的“当前版本 / 立即下载 / 当前政策”不得再出现历史版本漂移。

## 五、防再发机制

今后版本发布以 `app-release-manifest.json` 为唯一当前发布主数据。任何 Times26001 最新版本变更，CI 必须校验官网 APK 实体与 SHA-256、官网公开版本与最新构建版本、Google Play 候选版本、隐私政策、用户协议、当前发布面字符串、法律页共享样式和邮箱链接规范。任一项不同步即失败，不允许合并。

## 六、验收标准

- 官网“立即下载”真实下载 v1.1.14 / versionCode17 / API36 APK；
- 官网当前发布面不再残留 v1.1.13 / versionCode16；
- 隐私政策与用户协议显示 2026-08-27 和 v1.1.14 / code17 / API36；
- 法律/协议页面不再使用 980px 独立窄版心，统一跟随全站 1560px 内容轴；
- `admin@qilylean.com` 的下划线连续，不因 skip-ink 或地址换行出现断裂；
- Google Play 与官网 APK 签名链边界明确；
- 发布一致性 CI 全部通过后方可合并上线。
