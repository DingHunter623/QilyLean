# QilyLean全站统一规范补充条款｜2026-08-04｜同组卡片沉底对齐

## 1. 适用范围

适用于全站同组卡片中的信息标识条、结果条、资源摘要条、操作区及项目合作“专业边界”说明条。

## 2. 统一规则

1. 同一网格内的卡片采用纵向弹性布局并等高拉齐。
2. 信息标识条、结果条、边界说明条等底部语义模块统一沉底。
3. 信息标识条下方存在按钮组时，按钮组紧随标识条，不得单独占用中部弹性空白。
4. 项目合作三类边界卡片的“专业边界”说明条统一沉至卡片底部。
5. 仅调整纵向布局，不改变既有配色、文案、字号、边框和交互语义。

## 3. 禁止做法

- 不得通过空行、`<br>`、假占位或额外空白字符实现对齐。
- 不得写死卡片高度来掩盖内容差异。
- 不得使用绝对定位造成内容遮挡或移动端重叠。
- 不得因局部对齐要求擅自修改整张卡片背景、色界或文案。

## 4. 发布与验收

- 全站公共样式文件：`site-bottom-alignment-v1.css`。
- 发布脚本：`scripts/publish-bottom-alignment-standard.js`。
- 所有包含`</head>`的公开HTML页面必须加载当前版本样式。
- 自动校验必须确认发布幂等、全页覆盖和无旧版缺失。
- 后续静态页面生成或全站物化完成后，须重新执行本规范发布任务，防止回退。
