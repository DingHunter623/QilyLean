# QilyLean全站统一规范补充条款｜核心业务可读性与悬浮入口增补

版本：V2026.08.04 R3  
生效日期：2026-08-04

## 1. 三大核心业务序号

- 01／02／03统一采用深青实底、纯白数字、白色内描边和青色外圈。
- 禁止透明度、滤镜、同色文字、混合模式或低对比阴影影响识读。
- 用户仅要求序号清晰时，不得擅自改变整张业务卡片底色。

## 2. 三大核心业务卡片对齐

- 同排卡片按真实内容动态等高，不写死固定高度。
- 标题区、正文区、业务范围小方框、标准交付说明和合同入口按对应语义区统一对齐。
- 业务范围小方框统一行高、内边距、行间距和列间距。
- “标准交付”说明条沉底，其下合同入口保持同一底部基准线。
- 移动端取消跨卡片等高，按单列自然流式排列，避免空白和遮挡。

## 3. 全站悬浮功能栏

悬浮功能栏必须保留原有全部功能，并只在“首页”后新增“回顶部”。自上而下顺序统一为：

1. 首页
2. 回顶部
3. 本站搜索
4. 返回上一层
5. 分享当前页
6. 分享
7. 交流

- “回顶部”支持平滑滚动，同时保持悬浮栏原有拖动能力和键盘可访问性。
- 新增功能不得以任何理由删除、替换、隐藏或重排既有功能。
- 用户提出“增加一个模块”时，默认含义是增量修改；除非用户明确要求删除或精简，否则不得扩大整改范围。

## 4. 发布与防回退

- 公共CSS与JS必须注入全部公开HTML页面。
- 静态页面重建、全局导航发布、视觉物化及沉底对齐发布完成后，须自动复核并重新补齐本规范。
- 任一页面缺少原有六项功能、缺少第二项“回顶部”，或顺序不符合本规范，均判定为发布不合格。
- 自动校验必须同时确认首页、回顶部、本站搜索、返回上一层、分享当前页、分享和交流七项功能均存在。

## 5. 纠偏记录

R2曾错误地将“增加回顶部”解释为“仅保留首页、回顶部、本站搜索”，导致四项既有功能被删除。R3已废止该错误条款，恢复全部既有功能，并将“增量修改不得擅自删减”纳入强制规范。
