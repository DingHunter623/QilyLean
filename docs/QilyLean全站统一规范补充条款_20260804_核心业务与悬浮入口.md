# QilyLean全站统一规范补充条款｜核心业务可读性与悬浮入口精确排序

版本：V2026.08.04 R4  
生效日期：2026-08-04

## 1. 三大核心业务序号

- 01／02／03统一采用深青实底、纯白数字、白色内描边和青色外圈。
- 禁止透明度、滤镜、同色文字、混合模式或低对比阴影影响识读。
- 用户仅要求序号清晰时，不得擅自改变整张业务卡片底色。

## 2. 三大核心业务卡片对齐

- 同排卡片按真实内容动态等高，不写死固定高度。
- 标题区、正文区、业务范围小方框、标准交付说明和合同入口按对应语义区统一对齐。
- 业务范围小方框统一行高、内边距、行间距和列间距。
- “标准交付”说明条沉底，其下合同入口保持同一底部基准线。
- 移动端取消跨卡片等高，按单列自然流式排列，避免空白和遮挡。

## 3. 全站悬浮功能栏

悬浮功能栏必须保留七项功能，并严格按下列顺序自上而下排列：

1. 首页
2. 回顶部
3. 回上一层
4. 本站搜索
5. 分享当前页
6. 分享官网
7. 交流

### 3.1 文字口径

- “回顶部”不得写成“回到顶部”。
- “回上一层”不得写成“返回上一层”，即删除“返”字。
- 官网分享入口必须明确写为“分享官网”，不得只写“分享”。
- “分享当前页”与“分享官网”属于两个不同功能，不得合并、替换或混淆。

### 3.2 功能口径

- “首页”：返回QilyLean首页。
- “回顶部”：在当前页面平滑滚动至顶部，不发生页面跳转。
- “回上一层”：跳转至当前页面所属模块的上一级页面。
- “本站搜索”：打开站内搜索界面。
- “分享当前页”：分享或复制当前页面标题及网址。
- “分享官网”：分享QilyLean官网主页及官网二维码。
- “交流”：打开微信号、二维码及联系电话等交流入口。

### 3.3 变更边界

- 新增、改名、排序属于不同变更动作，必须分别执行，不得自行扩大范围。
- 用户给出明确顺序时，必须逐项对照，不得按开发习惯或历史顺序自行调整。
- 任何功能改名不得改变其原有功能逻辑。
- 悬浮栏须继续保持拖动能力、键盘可访问性及移动端可用性。

## 4. 发布与防回退

- 公共CSS与JS必须注入全部公开HTML页面。
- 静态页面重建、全局导航发布、视觉物化及沉底对齐发布完成后，须自动复核并重新补齐本规范。
- 自动校验必须确认七项功能全部存在，且DOM顺序严格为：`home → top → back → search → current → share → contact`。
- 自动校验必须确认页面文字分别为：首页、回顶部、回上一层、本站搜索、分享当前页、分享官网、交流。
- 任一页面出现“返回上一层”、仅写“分享”、顺序错误、功能缺失或重复按钮，均判定为发布不合格。

## 5. 纠偏记录

- R2错误地把“增加回顶部”解释为精简悬浮栏，擅自删除原有功能；该规则已废止。
- R3恢复了全部功能，但顺序仍为“本站搜索”在“回上一层”之前，且文字仍使用“返回上一层”和“分享”。
- R4根据功能定义进一步纠正为：`首页 → 回顶部 → 回上一层 → 本站搜索 → 分享当前页 → 分享官网 → 交流`，并将两处文字细节纳入强制验收。
