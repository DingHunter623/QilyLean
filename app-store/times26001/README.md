## 1. 商店名称与文案

### 应用名称
思大时间管理

### 副标题／一句话简介
黄历、闹钟、倒计时与IE现场分段测时工具

### 80字以内简介
集成北京时间、万年历、农历黄历、闹钟提醒、按秒倒计时、IE秒表分段、累计总时长和文本复制，适用于日常时间管理与工业工程现场测时。

### 详细介绍
思大时间管理是一款兼顾日常时间管理和工业工程现场测时的Android工具。

核心功能：
- 北京时间、公历、星期、周次、农历、节气与节假日；
- 黄历宜忌、冲煞、传统时辰等参考信息；
- 一次性、工作日、周末和自定义重复闹钟；
- 按秒显示的倒计时，到期响铃、振动和系统通知；
- IE现场秒表分段，分别记录本段时间与累计总时间；
- 分段记录、总时长和表格文本一键复制，便于粘贴到Excel/WPS；
- 深浅主题、字号、色弱模式和生日星座设置；
- 本地优先，不设账号、不投放广告、不接入第三方广告SDK。

“QilyLean AI｜启力精益”为IE时间分析自主开发的时间工具。
