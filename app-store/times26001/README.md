## 3. 商店名称与文案

### 应用名称
Times26001

### 副标题／一句话简介
工业工程时间研究与IE现场测时工具

### 80字以内简介
面向工业工程、现场改善与时间研究场景，提供IE秒表分段、累计总时长、倒计时、闹钟提醒及时间日历辅助功能，由QilyLean｜启力精益开发。

### 详细介绍
Times26001是一款以工业工程时间研究和制造现场测时为核心的Android工具，同时兼顾日常时间管理。

核心功能：
- IE现场秒表分段，分别记录本段时间与累计总时间；
- 分段记录、总时长和表格文本一键复制，便于粘贴到Excel/WPS；
- 按秒倒计时，到期响铃、振动和系统通知；
- 一次性、工作日、周末和自定义重复闹钟；
- 北京时间、公历、星期、周次、农历、节气与节假日；
- 黄历宜忌、冲煞、传统时辰等参考信息；
- 深浅主题、字号、色弱模式和生日星座设置；
- 本地优先，不设账号、不投放广告、不接入第三方广告SDK。

**Times26001由 QilyLean｜启力精益开发，面向工业工程、现场改善与时间研究场景提供专业测时能力。**
